★ RECOMMANDATION ★

SWITCHER POUR LES PAGES DISJOINTES,
STICKERS POUR LES PAGES PARTAGEES.

Aucune des 4 idees ne gagne seule. La carte de contenu montre un desequilibre : Positions / Scenarios sont quasi-disjoints (dupliques, donc switcher), tandis que Regles / Glossaire sont partages a ~75% (unifies, donc stickers).

★ PAGES QUI BASCULENT (A)
  • ▸ Accueil — hero & cartes adaptes au mode
  • ▸ Techniques — gestes filtres par discipline
  • ▸ Positions — 6v6 FIVB ou roles 2v2
  • ▸ Scenarios — rotations ou systemes beach
  • ▸ Guides — articles tagues par discipline
★ PAGES UNIFIEES (D)
  • ▸ Regles — reglement commun + encart "en beach"
  • ▸ Glossaire — 1 entree par terme, sticker INDOOR / BEACH / 2 EN 1

Pourquoi ? Un joueur indoor qui decouvre le beach veut comparer, pas changer de monde. Le glossaire et le reglement sont les endroits naturels du croisement.

★ ORDRE D'IMPLEMENTATION · POUR CLAUDE CODE ★
  1. 01
    MODELE DATA

    Ajouter discipline: ("indoor"|"beach")[] a toutes les entites. Backfill = ["indoor"].

  2. 02
    CONTEXTE + SWITCHER

    DisciplineContext persiste en localStorage("vw.discipline"). Switcher dans Layout.tsx, a droite du wordmark — tabs retro avec ombres.

  3. 03
    PRIMITIVES STICKERS

    <DisciplineBadge> en 3 variants : indoor (teal), beach (orange), both (mint).

  4. 04
    PAGES "BASCULE"

    Home, Techniques, Positions, Scenarios, Guides : lisent le contexte et branchent sur la bonne data. Pas de sticker sur ces pages — le switcher suffit.

  5. 05
    PAGES "UNIFIEES"

    Regles + Glossaire : ignorent le switcher, affichent les stickers + filtre [ Toutes / Indoor / Beach / Communs ].

  6. 06
    URL & SEO

    Switcher reflete en ?d=beach pour partage de liens. Pages unifiees independantes.

★ SNIPPET TYPESCRIPT ★
// src/contexts/Discipline.tsx
type Discipline = "indoor" | "beach";

const DisciplineContext = createContext<{
  d: Discipline;
  set: (d: Discipline) => void;
}>(...);

// dans une page "bascule"
const { d } = useDiscipline();
const positions = d === "beach"
  ? POSITIONS_BEACH
  : POSITIONS_INDOOR;

// dans une page "unifiee" --- pas de useDiscipline

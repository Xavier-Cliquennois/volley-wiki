01 — Principes
Fondations

Principes de design

⚡

Brutalisme numérique

Esthétique terminal : bordures nettes, pas de coins arrondis, contrastes francs. Le contenu prime sur la décoration.

🎯

Lisibilité technique

Police monospace partout. Les titres en MAJUSCULES avec tracking-widest renforcent l'aspect documentation.

🟡

Mono-accent jaune

Une seule couleur d'accent (jaune-400) pour les actions, liens actifs et éléments importants. Le reste reste en niveaux de gris.

📐

Grilles strictes

Largeur max 6xl (72rem). Espacements verticaux par paliers (space-y-6/8/16). Hiérarchie via la taille et l'épaisseur.

Fiches résumé (points clés / erreurs)

Points clés

  • ▸ Deuxième point clé, idéalement 3 à 5 maximum.
Erreurs fréquentes
  • ✗ Description d'une erreur courante à éviter.
  • ✗ Deuxième erreur, formulation cause → conséquence.

Hiérarchie : points clés (bordure standard, bullet jaune) versus erreurs (bordure subtile, croix grise).
